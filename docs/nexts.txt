###Rules
Add this rule to all agents

Every agent must obey:
On any received task:
1. Send ACK immediately.
2. Send WIP every 20–30 seconds while working.
3. If blocked, send BLOCKED with reason.
4. If asking another agent, send REQUEST.
5. When finished, send RESULT.
6. Then send DONE.
